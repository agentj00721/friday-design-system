# Friday Design Tokens

Friday is an AI-native insurance guidance platform. The system should feel calm, intelligent, factual, and human.

## Color

| Token | Value | Use |
| --- | --- | --- |
| `--friday-ink` | `#082828` | Deep emerald ink, primary dark identity |
| `--friday-emerald` | `#0FA98F` | Path symbol, active states, primary action |
| `--friday-mint` | `#8FE3C2` | Glow, focus rings, progress signals |
| `--friday-soft-mint` | `#E6F6F1` | Light panels and atmospheric wash |
| `--friday-pearl` | `#F7FAF9` | Premium light-mode base |
| `--friday-navy` | `#0F172A` | Neutral depth |
| `--friday-slate` | `#64748B` | Secondary copy |
| `--friday-mist` | `#CBD5E1` | Dividers and quiet borders |

## Typography

- Display: Recoleta-style editorial serif behavior. This site uses Cormorant Garamond as an available web-native stand-in.
- Interface and body: Inter.
- Code and token labels: JetBrains Mono.

## Motion

- Default reveal: `420ms cubic-bezier(.22, 1, .36, 1)`.
- Path motion is directional and sequential.
- Glow intensifies on focus, not as decoration.

## Product Truths

- Friday does not recommend products.
- Friday does not replace brokers or licensed advice.
- Comparisons are factual.
- The user decides. The broker advises. Friday guides.
